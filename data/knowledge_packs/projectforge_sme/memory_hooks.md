# ProjectForge SME — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

- Durable learning related to agent harness
- Durable learning related to workspace envelopes
- Durable learning related to tool guards
