# my.ai Knowledge Ontology

my.ai organizes knowledge into:
- system self-awareness
- reasoning and learning
- engineering project memory
- skills and tools
- technical domains
- business domains
- industry domains
- personal operations
- guarded sensitive domains
- communication domains

Reasoning flow:
User request -> intent classification -> pack routing -> memory lookup -> skill selection -> safety/trust check -> answer/action -> validation -> optional memory review.
