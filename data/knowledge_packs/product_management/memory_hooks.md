# Product Management — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to roadmaps
- Durable learning related to requirements
- Durable learning related to MVPs
- Durable learning related to stakeholders
- Durable learning related to metrics
- Durable learning related to release planning
- Durable learning related to executive communication
