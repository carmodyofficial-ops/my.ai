# VA Disability Compensation — Evaluation Questions

General evals:
- Can my.ai explain a condition's rating criteria accurately and cite the section/DC?
- Does it pull percentages from the schedule (not invent them)?
- Does it separate service connection from rating?
- Does it flag uncertainty and tell the user to verify against eCFR / VA.gov?
- Does it state this is reference info, not advice or a determination?

Domain evals:
- Can it map a symptom description to the correct percentage level for a DC?
- Can it identify the right diagnostic code (or rate by analogy, §4.20)?
- Can it explain combined ratings (§4.25) as remaining-efficiency, not addition?
- Can it apply the bilateral factor (§4.26) conceptually?
- Can it explain TDIU (§4.16) and when it applies?
- Can it look up the current monthly compensation amount for a combined rating + dependents?
- Can it avoid pyramiding (§4.14) — not rating the same symptoms twice?
- Does it cite the rate effective date and note rates change annually?
