# VA Disability Compensation — Core Concepts

- **Service connection** — the link between a disability and military service. Requires
  (1) a current diagnosis, (2) an in-service event/injury/exposure, and (3) a medical
  **nexus** connecting them. Compensation only flows once service-connected. (38 CFR Part 3.)
- **Rating (%)** — the measure of how disabling a service-connected condition is, in
  10% increments (0–100%), set by the **Schedule for Rating Disabilities** (38 CFR Part 4).
- **Diagnostic code (DC)** — a 4-digit code identifying the condition and the criteria
  used to rate it (e.g., 6260 tinnitus, 8100 migraine, 6847 sleep apnea, 9411 PTSD).
- **Rating criteria** — the symptom/severity descriptions that define each percentage
  level for a DC. The assigned level is the one the evidence **more nearly approximates**
  (§4.7); reasonable doubt goes to the claimant (§4.3).
- **Combined rating** — multiple disabilities are combined via the **Combined Ratings
  Table (§4.25)** on remaining efficiency (NOT addition), rounded to the nearest 10%.
- **Bilateral factor (§4.26)** — extra 10% of the combined value for disabilities of
  paired extremities (both arms / both legs).
- **TDIU (§4.16)** — pays at the **100% rate** when service-connected disabilities
  prevent substantially gainful employment, even without a 100% schedular rating.
- **Pyramiding (§4.14)** — the same symptoms cannot be rated under two codes.
- **Analogous rating (§4.20)** — an unlisted condition is rated under a closely related
  listed DC.
- **0% (noncompensable)** — service connection established but symptoms below the
  compensable threshold; matters because it preserves connection if the condition worsens.
- **Effective date** — when entitlement began; drives any back pay.
- **Static vs. re-examined / protected ratings** — some ratings face future C&P exams;
  long-stable ratings can become protected from reduction.
- **Compensation rate** — the monthly tax-free dollar amount for the combined rating and
  dependents (see `comp_rates.md`).
