# Procedures — Answering a VA Rating Question

## Look up a condition's rating criteria
1. Identify the **body system / diagnostic code** for the condition (e.g., migraine →
   neurological §4.124a DC 8100; sleep apnea → respiratory §4.97 DC 6847).
2. Open the matching `sections/sec_4_x.md` (full schedule) or use corpus search; read
   the **levels and criteria** for that DC.
3. State each percentage with its criteria and **cite the section/DC** verbatim-faithful.
4. Note any cross-references (e.g., "rate hearing impairment separately", notes, exceptions).

## Estimate a combined rating (explain, don't adjudicate)
1. List each service-connected condition's individual rating.
2. Combine via the **Combined Ratings Table (§4.25)** (remaining-efficiency method, not
   addition); apply the **bilateral factor (§4.26)** to paired-extremity ratings first.
3. Round the final combined value to the nearest 10%.
4. Map the combined rating + dependents to a monthly amount in `comp_rates.md`.

## Decide which code applies
- Use the listed DC if the condition is named; otherwise rate by **analogy (§4.20)** to
  the closest listed condition.
- When two evaluations could apply, choose the one the disability picture **more nearly
  approximates (§4.7)**; do not double-count symptoms (**no pyramiding, §4.14**).

## Always
- Separate **service connection** (is it connected?) from **rating** (how severe?).
- Cite the regulation section/DC and the VA.gov rate effective date.
- State that this is **reference information**, not a determination; refer real claims to
  an accredited VSO/attorney and VA.gov. Verify current values against eCFR / VA.gov.
