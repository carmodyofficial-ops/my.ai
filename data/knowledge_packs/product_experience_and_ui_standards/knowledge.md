# Product Experience and UI Standards

Purpose: Preserve the my.ai product feel and usability.

Brand:
- Product name: my.ai.
- Prior Your.AI branding should be replaced where scoped.
- Theme should be neutral/light grey.
- Preserve semantic error, warning, danger, and destructive colors.

Guest login UX:
- Login page may show Guest access hint.
- Guest should not see confusing admin-only controls.
- Guest should not see signup as a primary path.
- Guest experience should be simple for household/LAN users.

Admin UX:
- Admin controls remain available to Admin only.
- User management remains protected.
- Settings remain protected.

Mobile/LAN:
- The app should be usable from phone/tablet on same Wi-Fi.
- LAN URL should be easy to communicate.
- Avoid UI that assumes only localhost desktop use.
