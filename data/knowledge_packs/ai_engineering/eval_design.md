# ai_engineering — Eval Design

Purpose: deepen the ai_engineering knowledge pack so my.ai can reason, verify, select skills, handle uncertainty, and learn from validated work.

Required concepts:
eval knowledge recall retrieval relevance skill selection tool guard memory policy hallucination resistance

Operational guidance:
- Separate facts from assumptions.
- Prefer validation before claiming success.
- Preserve local-only and security boundaries.
- Use memory only for durable, useful, verified context.
- Use knowledge packs for reusable domain knowledge.
- Add evals when behavior should be tested later.
