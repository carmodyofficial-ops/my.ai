# AI Engineering — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to LLMs
- Durable learning related to RAG
- Durable learning related to agents
- Durable learning related to embeddings
- Durable learning related to evals
- Durable learning related to model routing
- Durable learning related to hallucination control
