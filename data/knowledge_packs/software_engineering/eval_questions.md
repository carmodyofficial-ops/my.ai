# Software Engineering — Evaluation Questions

General evals:
- Can my.ai explain the subject accurately?
- Can my.ai identify uncertainty?
- Can my.ai recommend validation?
- Can my.ai avoid hallucinating specifics?
- Can my.ai apply the knowledge to a real task?

Domain evals:
- Can my.ai reason about architecture?
- Can my.ai reason about testing?
- Can my.ai reason about debugging?
- Can my.ai reason about APIs?
- Can my.ai reason about refactoring?
- Can my.ai reason about releases?
- Can my.ai reason about technical debt?
