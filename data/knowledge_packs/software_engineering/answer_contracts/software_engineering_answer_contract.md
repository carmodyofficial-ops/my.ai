# Software Engineering Answer Contract

Use for architecture, implementation, debugging, refactoring, integration, and technical planning.

## Required Sections

1. Objective
2. Current-state understanding
3. Proposed design or fix
4. Files or modules impacted
5. Implementation steps
6. Validation plan
7. Regression test plan
8. Risks and edge cases
9. Rollback plan
10. Next actions

## Quality Bar

- Be specific about paths, functions, interfaces, data flow, and failure modes.
- Include concrete commands when the user is working in a terminal.
- Include acceptance criteria.
- Do not stop before rollback and validation.
