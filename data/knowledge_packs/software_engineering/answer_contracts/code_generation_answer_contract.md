# Code Generation Answer Contract

Use when generating or modifying code.

## Required Sections

1. Purpose
2. Complete implementation
3. Dependencies
4. How to run
5. Minimal tests
6. Expected output
7. Edge cases
8. Validation checklist

## Code Rules

- Provide full runnable code when requested.
- Avoid placeholder-only implementations.
- Avoid unexplained partial snippets when a full file is required.
- Include tests for normal path and at least one failure or edge path.
- Include commands to execute tests.
