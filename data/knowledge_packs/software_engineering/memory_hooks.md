# Software Engineering — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to architecture
- Durable learning related to testing
- Durable learning related to debugging
- Durable learning related to APIs
- Durable learning related to refactoring
- Durable learning related to releases
- Durable learning related to technical debt
