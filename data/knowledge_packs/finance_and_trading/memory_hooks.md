# Finance and Trading — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to risk management
- Durable learning related to market structure
- Durable learning related to backtesting
- Durable learning related to position sizing
- Durable learning related to crypto
- Durable learning related to strategy evaluation
- Durable learning related to non-advisory limits
