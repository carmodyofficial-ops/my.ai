# Aviation Operations — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to crew workflows
- Durable learning related to inflight systems
- Durable learning related to airport operations
- Durable learning related to onboard sales
- Durable learning related to safety
- Durable learning related to KPIs
- Durable learning related to reliability
