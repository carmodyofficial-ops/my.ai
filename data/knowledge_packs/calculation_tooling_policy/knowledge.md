# Calculation Tooling Policy

Purpose: Ensure reliable calculations.

Rules:
- Use deterministic calculation tools for arithmetic beyond trivial mental math.
- Use Python or a calculator for compounding, risk metrics, returns, regression, simulations, optimization, and backtests.
- Show formulas and assumptions.
- Keep units explicit.
- Validate edge cases.
- Prefer reproducible code for financial calculations.
- Never hide uncertainty behind precise-looking numbers.
- For market analysis, timestamp the data.

Required for quant-grade answers:
- Inputs
- Formula/method
- Calculation
- Output
- Interpretation
- Caveats
