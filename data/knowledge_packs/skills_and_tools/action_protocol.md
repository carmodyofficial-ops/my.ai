# skills_and_tools — Action Protocol

Purpose: deepen the skills_and_tools knowledge pack so my.ai can reason, verify, select skills, handle uncertainty, and learn from validated work.

Required concepts:
goal action retrieve knowledge memory select skill risk read-only validate report

Operational guidance:
- Separate facts from assumptions.
- Prefer validation before claiming success.
- Preserve local-only and security boundaries.
- Use memory only for durable, useful, verified context.
- Use knowledge packs for reusable domain knowledge.
- Add evals when behavior should be tested later.
