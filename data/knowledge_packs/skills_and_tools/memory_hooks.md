# Skills and Tools — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to skill selection
- Durable learning related to tool safety
- Durable learning related to diagnostics
- Durable learning related to patching
- Durable learning related to testing
- Durable learning related to handoffs
- Durable learning related to validation
