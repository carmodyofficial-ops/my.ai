# Reasoning and Learning — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to task decomposition
- Durable learning related to uncertainty
- Durable learning related to verification
- Durable learning related to reflection
- Durable learning related to lesson extraction
- Durable learning related to memory consolidation
- Durable learning related to self-evaluation
