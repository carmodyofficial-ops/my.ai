# Reasoning and Learning — Learning Loop

Learning loop:
1. Observe task/result.
2. Compare expected vs actual.
3. Identify failure or success pattern.
4. Extract lesson.
5. Decide whether lesson is durable.
6. Store as memory or pack update.
7. Add eval question.
8. Re-test later.

This is how my.ai should improve without simply accumulating noisy notes.
