# Research Methods — Evaluation Questions

General evals:
- Can my.ai explain the subject accurately?
- Can my.ai identify uncertainty?
- Can my.ai recommend validation?
- Can my.ai avoid hallucinating specifics?
- Can my.ai apply the knowledge to a real task?

Domain evals:
- Can my.ai reason about source evaluation?
- Can my.ai reason about evidence grading?
- Can my.ai reason about assumptions?
- Can my.ai reason about citations?
- Can my.ai reason about recency?
- Can my.ai reason about counterarguments?
- Can my.ai reason about synthesis?
