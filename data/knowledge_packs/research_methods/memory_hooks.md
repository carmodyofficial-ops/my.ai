# Research Methods — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to source evaluation
- Durable learning related to evidence grading
- Durable learning related to assumptions
- Durable learning related to citations
- Durable learning related to recency
- Durable learning related to counterarguments
- Durable learning related to synthesis
