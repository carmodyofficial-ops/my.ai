# Data and Databases — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to schemas
- Durable learning related to SQL
- Durable learning related to indexing
- Durable learning related to migrations
- Durable learning related to pipelines
- Durable learning related to analytics
- Durable learning related to data quality
