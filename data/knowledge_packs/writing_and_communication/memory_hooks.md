# Writing and Communication — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to emails
- Durable learning related to resumes
- Durable learning related to executive summaries
- Durable learning related to technical docs
- Durable learning related to tone
- Durable learning related to interviews
- Durable learning related to stakeholder messaging
