# Kubernetes and Cloud-Native Answer Contract

Use for Kubernetes, Docker, services, ingress, secrets, deployment, observability, and infrastructure operations.

## Required Sections

1. Objective
2. Architecture or resource summary
3. Manifests or commands
4. Security and secret handling
5. Deployment steps
6. Health checks
7. Observability checks
8. Rollback plan
9. Failure modes
10. Final validation checklist

## Quality Bar

- Include kubectl, docker, helm, or compose commands where relevant.
- Include readiness/liveness or equivalent health validation.
- Include rollback commands or rollback decision points.
- Never expose secrets.
