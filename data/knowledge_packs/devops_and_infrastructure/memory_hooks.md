# DevOps and Infrastructure — Memory Hooks

Good memory candidates:
- durable user preferences
- stable project facts
- validated decisions
- repeated workflows
- lessons learned

Bad memory candidates:
- one-off details
- unverified guesses
- sensitive personal details unless explicitly requested
- temporary troubleshooting artifacts

Pack-specific hooks:
- Durable learning related to Docker
- Durable learning related to compose
- Durable learning related to health checks
- Durable learning related to logs
- Durable learning related to deployment
- Durable learning related to backup/restore
- Durable learning related to observability
